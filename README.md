## Mark · backend y automatización

Hago la parte que no se ve: APIs, bases de datos, bots y scripts que te ahorran trabajo manual.
Trabajo sobre todo con **Python**, y también con Node.js cuando el proyecto lo pide.

### Qué tipo de trabajos hago

- **APIs REST** para apps y páginas web, con su base de datos y documentación.
- **Integraciones**: conectar tu tienda, formulario o CRM con Google Sheets, Mercado Pago, WhatsApp u otra API.
- **Bots** de Telegram y WhatsApp: avisos, respuestas automáticas, consultas.
- **Automatizar planillas**: leer Excel o CSV, limpiar datos y armar reportes listos para mandar.
- **Arreglos puntuales**: un script que dejó de andar, un error en el backend, una consulta SQL lenta.
